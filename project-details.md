# Project Details — Arket Power BI Dashboard

## Objective

Build an interactive business intelligence report for monitoring sales performance and enabling analysis across products, customers, geography, salespeople, and time.

## Analytical Questions Covered

- What is the overall sales value and sales quantity?
- How are current-day metrics performing compared with the previous day?
- How does sales performance vary by fiscal year?
- Which products/product groups contribute to sales?
- How does performance vary by customer, company, city, state, country, and area?
- How do salespeople compare in terms of business performance?
- What are the month-on-month and year-over-year sales patterns?
- Where are the largest sales variances and percentage changes?

## KPI Layer

The report definition contains KPI measures including Total Sales Value (Cr), Total Sale Quantity, Current Day Sale (Cr), Current Day Qty (Lakh), Previous Day Sale (Cr), Previous Day Qty (Lakh), Current Year Month Sale, Last Year Month Sale, Sales Variance, Sales Variance in %, Avg Sale Quantity, Avg Sale Value, Avg Quantity by Month, and Avg Value by Month.

## Visual Design

The report uses a combination of:

- KPI cards
- Column charts
- Clustered bar/column charts
- Line charts
- Line + stacked column combination charts
- Tables and matrix/pivot-style visuals
- Slicers
- Navigation/action buttons
- Custom icons and branded visual elements

## Recruiter Summary

This project demonstrates practical Power BI experience beyond basic chart creation: the report combines KPI reporting, time intelligence, interactive filtering, navigation, dimensional analysis, and business-focused visualization across multiple report pages.
